# snoby/hermes-skills

Hermes Agent skills, installable directly:

```bash
hermes skills install https://raw.githubusercontent.com/snoby/hermes-skills/main/skills/animated-scenario-diagrams/SKILL.md
```

Or add the whole repo as a tap:

```bash
hermes skills tap add https://github.com/snoby/hermes-skills
hermes skills search animated-scenario-diagrams
hermes skills install animated-scenario-diagrams
```

## Skills

| Skill | Description |
|---|---|
| `animated-scenario-diagrams` | Animated dark-mode scenario diagrams as one HTML file. |
